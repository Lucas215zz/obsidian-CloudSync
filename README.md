# Obsidian 同步插件（Tencent COS Sync）

把 Obsidian 仓库实时 / 定时同步到腾讯云对象存储（COS），并支持多台设备安全同步，不丢文件。

> 本插件的中文名为「obsidian同步插件」，英文名 / 插件 ID 为 `obsidian-cos-sync`。

## 功能特性

- **实时同步**：本地文件创建 / 修改 / 删除后自动同步（2 秒防抖）
- **定时同步**：按固定间隔轮询云端，拉取其他设备改动
- **多端安全**：基于「上次同步状态」的三方比对，不会互相覆盖
- **冲突保护**：本地与云端同时修改时，默认保留双方，生成 `xxx (conflict 时间戳).md`，绝不静默丢数据
- **删除保护**：同步导致的本地删除会先移入 Obsidian 回收站（`.trash`），可恢复
- **增量高效**：用 mtime + 大小缓存，未变化的文件不重复计算哈希

## 同步原理（三方比对）

每台设备在本地保存一份 `sync-state.json`，记录每个文件上次同步时的：

- `localMd5`：本地文件内容 MD5
- `remoteEtag`：云端对象 ETag

每次同步对每个文件做对比：

| 本地改动 | 云端改动 | 动作 |
| --- | --- | --- |
| 无 | 无 | 跳过 |
| 有 | 无 | 上传本地 → 云端 |
| 无 | 有 | 下载云端 → 本地 |
| 有 | 有 | 冲突，按策略处理 |
| 本地新增 | 无 | 上传 |
| 云端新增 | 无 | 下载 |
| 本地删除 | 无 | 删除云端对象 |
| 无 | 云端删除 | 删除本地（移入回收站） |
| 本地删除 | 云端有改动 | 下载云端（云端改动优先，避免丢内容） |
| 本地有改动 | 云端删除 | 重新上传本地（本地改动优先） |

关键点：删除和修改冲突时，永远倾向于保留有内容的那一方，而不是直接删除。

说明：文件重命名会表现为删除 + 新增，由上述规则安全收敛，不会丢内容。

## 安装

1. 克隆 / 下载本项目到某个目录
2. 安装依赖并构建：

```bash
npm install
npm run build
```

3. 把生成的文件复制到你的 vault 的插件目录：

```text
<vault>/.obsidian/plugins/obsidian-cos-sync/
  ├── main.js
  ├── manifest.json
  └── styles.css
```

4. 重启 Obsidian，在「设置 → 第三方插件」中启用「Tencent COS Sync」。

开发调试可运行 `npm run dev` 启动 esbuild watch 模式。

> 也可使用仓库内的 `安装插件.command`（macOS）或 `安装插件.bat`（Windows）一键复制构建产物到插件目录。

## 配置腾讯云 COS

1. 在腾讯云控制台创建存储桶，记下：
   - `Bucket`：形如 `mybucket-1250000000`
   - `Region`：形如 `ap-guangzhou`
2. 在访问管理 CAM 创建子账号（或使用现有密钥），拿到 `SecretId` / `SecretKey`。
   - 强烈建议使用子账号，并只授予该存储桶的最小权限（`PutObject`、`GetObject`、`DeleteObject`、`GetBucket`）。
3. 在插件设置里填写以上信息，`Prefix` 建议填 `obsidian/`（不同仓库用不同前缀隔离）。

## 多设备使用建议

- 每台设备安装本插件，填写相同的 Bucket / Region / Prefix（密钥可不同账号）。
- 各设备首次同步会拉取云端现有文件。
- 若两台设备同时改了同一文件，会自动生成冲突副本，手动合并后删除副本即可。
- 默认不同步 `.obsidian`（各设备插件配置独立）；如需同步配置可在设置里开启。

## 冲突策略说明

| 策略 | 行为 |
| --- | --- |
| 双方都保留（本地为准）*默认* | 云端版本另存为冲突副本，本地版本上传 |
| 双方都保留（云端为准） | 本地版本另存为冲突副本，云端版本覆盖本地 |
| 本地覆盖云端 | 本地内容上传，云端内容丢失 |
| 云端覆盖本地 | 云端内容下载，本地内容丢失（可先入回收站） |
| 跳过 | 两边都不动，仅记录状态 |

## 构建说明

`cos-nodejs-sdk-v5` 会被 esbuild 打包进 `main.js`，Node 内置模块（`crypto`、`stream`、`http` 等）保持外部引用，由 Obsidian 的 Electron 运行时提供，因此仅支持桌面端（`isDesktopOnly: true`）。
